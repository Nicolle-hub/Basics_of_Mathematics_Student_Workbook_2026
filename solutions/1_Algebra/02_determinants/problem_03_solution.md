Exercise 3 Solution

Matrix A is:

(
  1  2  0
  0  3  1
  2  1  1
)

Expand its determinant along the first row:

determinant of A = 1 * (3 * 1 - 1 * 1) - 2 * (0 * 1 - 1 * 2)
                 = 1 * 2 - 2 * (-2)
                 = 2 + 4
                 = 6

Swap the first and second rows to form matrix B:

(
  0  3  1
  1  2  0
  2  1  1
)

Swapping two rows changes the sign of the determinant. Therefore:

determinant of B = -determinant of A = -6

Check by expanding along the first row of B:

determinant of B = -3 * (1 * 1 - 0 * 2) + 1 * (1 * 1 - 2 * 2)
                 = -3 + (1 - 4)
                 = -6

The calculation confirms the prediction.
