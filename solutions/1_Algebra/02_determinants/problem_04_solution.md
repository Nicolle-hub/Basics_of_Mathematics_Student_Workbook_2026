Exercise 4 Solution

The matrix is upper triangular:

(
  2   4  1
  0  -3  5
  0   0  7
)

For any triangular matrix, the determinant is the product of the diagonal entries. Therefore:

determinant = 2 * (-3) * 7
            = -42

The determinant is -42. The rule applies because all entries below the main diagonal are zero.
