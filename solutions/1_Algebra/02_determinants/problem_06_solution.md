Exercise 6 Solution

The matrix is:

(
  t  1
  2  t
)

Its determinant is:

determinant = t * t - 1 * 2
            = t^2 - 2

A matrix is not invertible when its determinant is zero. Set the determinant equal to zero:

t^2 - 2 = 0
t^2 = 2
t = sqrt(2) or t = -sqrt(2)

Conclusion

The matrix is not invertible for t = sqrt(2) and t = -sqrt(2). For all other real values of t, it is invertible.
