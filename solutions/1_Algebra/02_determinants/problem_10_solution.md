Exercise 10 Solution

The matrix has rows:

(
  1  2  3
  2  4  6
  0  1  5
)

The second row is twice the first row:

row 2 = 2 * row 1

Therefore, the rows are linearly dependent. Subtracting twice row 1 from row 2 would produce a zero row. A determinant with a zero row is zero, so the determinant of this matrix is zero.

Linearly dependent rows also mean the square matrix is not invertible.

Conclusion

The determinant is zero because row 2 is twice row 1. The matrix is not invertible.
